## How to install this project

1. Pull this project
2. Make sure you are on the correct branch, ( jangan sampai salah yaa pak :D )
3. Create Environment Python

```
python -m venv venv
```

3. Activate env

for Windows :
```
.\venv\Script\Activate.ps1

or

venv/Script/activate.bat

or

venv/Script/activate
```

for mac or linux:
```
source venv/Script/activate
```

4. install the package

```
pip install
```


5. run compare test

```
python compare_csv_parquet/main.py
```
